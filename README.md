# Contrátame!

Marketplace móvil para conectar clientes con trabajadores independientes en Bolivia.

## Aplicaciones

- `apps/mobile/` — aplicación Expo/React Native para clientes y trabajadores.
- `apps/admin/` — panel Next.js de aprobación administrativa de perfiles profesionales.
- `supabase/` — configuración, migraciones y pruebas pgTAP del backend compartido.
- `docs/` — requisitos, arquitectura, modelo de datos, módulos, pruebas e implementación.

Antes de realizar cambios, leer `AGENTS.md` y la documentación del módulo correspondiente. Las migraciones se validan localmente antes de cualquier despliegue remoto.
